# pazaborgs.github.io

Portfólio de Engenharia de Dados e Analytics de Patrick Regis, publicado via GitHub Pages em [pazaborgs.github.io](https://pazaborgs.github.io/).

## Estrutura modular

```text
pazaborgs.github.io/
├── index.html                 # Conteúdo e marcação HTML (seções comentadas)
└── assets/
    ├── favicon.svg            # Ícone de banco de dados exibido na aba do navegador
    └── css/
        ├── tokens.css         # Paleta editorial (OWID) e fontes
        ├── layout.css         # Estrutura geral, navegação, hero, projetos, sobre e rodapé
        └── charts.css         # Gráficos de barras, linha de referência e tabelas
```

## Onde editar cada coisa

- **Mudar cores ou fontes:** `assets/css/tokens.css`
- **Mudar espaçamentos ou layout:** `assets/css/layout.css`
- **Ajustar gráficos ou tabelas:** `assets/css/charts.css`
- **Trocar o ícone da aba:** `assets/favicon.svg`
- **Atualizar textos, links, projetos ou números:** `index.html` (basta abrir no navegador localmente para pré-visualizar — não exige build nem servidor)
